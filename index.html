Nioh 3 Builder

The repo is live. One more file is needed on GitHub so this page becomes the real builder.

  1. On your phone or computer, download nioh3-set-builder.html from the Grok chat.
  2. Open the repo.
  3. Tap Add file → Upload files.
  4. Upload that file, then rename it to index.html (replace this page).
  5. Repo → Settings → Pages → Source: GitHub Actions.
  6. Wait about a minute, then open:
    https://realcitizensnips.github.io/nioh3-builder/
  7. In Safari: Share → Add to Home Screen.

After that, new versions can be pushed to this same repo.
